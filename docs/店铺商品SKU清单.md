## 二、编码与价格规则

1. **店铺编码**：`S` + 两位序号，`S01`–`S66`，按店铺在商品列表中首次出现的顺序分配，不复用。
2. **商品编码**：`P` + 三位序号，`P001`–`P150`，与 `Product.id` 一一对应。
3. **SKU 编码**：`S{店铺}-P{商品}-{序号}`，例 `S01-P001-03`；序号 `01` 固定为主推规格。
4. **价格口径**：商品展示价 = `-01` SKU 售价，必须等于 `Product.price`；其余 SKU 可低于或高于展示价。
5. **差异维度**：同一商品的 SKU 只允许在颜色、口味、容量、尺寸、数量、套装、服务时长上做差异；颜色 / 口味一般同价，容量 / 尺寸 / 套餐按档加价。
6. **价格区间**：0.99–12999；`originalPrice` 必须大于 `price`，`sold` 单位为万件，`rating` 落在 4.7–4.9。
7. 本清单标注的价格为规划口径；接入代码前，一切以 `lib/data.dart` 的 `Product.price` 为准。

## 五、维护约定

1. **新增商品**：先在 `P` 号段取未被占用的编号 → 在本清单登记店铺归属与 SKU → 再改 `lib/data.dart` → 最后补测试断言。
2. **店铺变更**：`store` 字段改名、合并或拆分，必须同步本清单与所有引用该店铺的商品，不允许只改代码。
3. **SKU 变更**：`-01` 始终是主推规格，售价与 `Product.price` 绑定；删除 SKU 后其编码作废，不复用。
4. **关联数据同批更新**：改商品编号或归类时，同步检查 `seckillIds`（秒杀）、`liveRooms[].productIds`（直播间）、`hotSearches`（热搜）。
5. **数量基线**：店铺 66、商品 150、SKU 456；任一数字变化，必须更新本文档「一、总览」与项目规则中的基线。
